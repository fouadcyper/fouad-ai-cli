# Offline bundles

Run `scripts/build-offline-bundle.sh <platform> <verified-runtime> <verified-model> <sha256-manifest>`. Publication is always a human action. Exact model redistribution rights must be reviewed before inclusion; otherwise distribute a one-command verified downloader, not weights.

Expected names: `fouad-ai-full-linux-x64.tar.zst`, `fouad-ai-full-linux-arm64.tar.zst`, `fouad-ai-full-windows-x64.zip`, `fouad-ai-full-macos-arm64.tar.zst`, `fouad-ai-full-macos-x64.tar.zst`.
