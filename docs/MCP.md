# MCP

FOUAD AI targets the production v1 `@modelcontextprotocol/sdk`, supporting stdio and Streamable HTTP concepts. HTTP+SSE is legacy. Server configuration must map only named environment variables and secret references. Discovery does not grant execution permission; each tool retains its own risk and timeout.

The current CLI provides configuration command surfaces and a unified tool registry. Full transport activation is gated until server persistence and per-tool approval UI are complete; it does not falsely report a connection.
